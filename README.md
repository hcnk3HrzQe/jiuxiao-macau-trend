# 澳门 · 九肖中特连中榜 + 家禽野兽 · 每小时票数快照

追踪第三方论坛（`lotteryType=2` 澳门）两条数据流，每期从开局到开奖的**票数上涨过程**：

1. **九肖中特 连中榜**（`tid=31`）：榜单成员的选肖累加票数
2. **家禽野兽**（`tid=62`）：该玩法**全部发帖人**的「家禽/野兽」票数（论坛搜索列表）

> ⚠ **两条流人群不同**：九肖票来自「连中榜成员」（约数百人）；家禽野兽票来自「该玩法全部发帖人」（约十来人）。故分字段存放，**不要混算**。
> 帖子发出即**锁定**（实测开奖前不能改、也不能删），所以家禽野兽票数**只增不减**，是干净的累计曲线。

- 自动抓取（GitHub Actions 定时任务）：**常规每小时 4 档冗余**（15 分钟一档，实测约每 30 分钟落地一条）；**开奖前加密到每 5 分钟 1 条**（中国时间 **21:02 ~ 21:32**，错开整点与 5 分刻度降延迟）
- **外部兜底触发**：Cloudflare Worker（`jqys-snap-timer`）在**同一批 UTC 时刻**（`:08/:23/:38/:53` 及开奖前 `13:02~13:32`）额外 `workflow_dispatch` 拉起同一条 workflow —— 用于兜住 GitHub `schedule` 的**丢档**。与 GitHub 触发若落在 2 分钟内，采集脚本按「<120s 覆盖」规则自动并轨，不会产生重复记录。
- 一期一个文件，每次往文件末尾**追加一条**记录
- 到下一期自动切到新文件（**按数据里的期号切，不靠时钟**）

## 数据格式

`data/{期号4位}.json` —— 一个 JSON 数组，每行一条：

```json
[
{"t":"2026-10-18T00:00:04+08:00","period":291,"drawAt":"2026-10-18T21:32:00+08:00","board":400,"n":12,"votes":{"鼠":1,"牛":0,"虎":0,"兔":0,"龙":2,"蛇":0,"马":1,"羊":0,"猴":0,"鸡":3,"狗":0,"猪":0},"jqys":{"n":8,"votes":{"家禽":3,"野兽":5}}},
{"t":"2026-10-18T01:00:03+08:00","period":291,"drawAt":"2026-10-18T21:32:00+08:00","board":400,"n":63,"votes":{"鼠":4,"牛":3,"虎":1,"兔":1,"龙":6,"蛇":2,"马":3,"羊":1,"猴":2,"鸡":8,"狗":1,"猪":1},"jqys":{"n":10,"votes":{"家禽":3,"野兽":7}}}
]
```

| 字段 | 含义 |
|---|---|
| `t` | 本次抓取时刻（东八区 `+08:00`） |
| `period` | 当期期号（当前未开奖的那期） |
| `drawAt` | 该期开奖时刻（东八区） |
| `board` | 九肖连中榜人数 |
| `n` | 九肖：已发帖（已投票）人数，随时间上涨 |
| `votes` | 九肖：12 生肖 → 票数；随时间上涨 |
| `jqys.n` | 家禽野兽：当期发帖人数，随时间上涨 |
| `jqys.votes` | 家禽野兽：`家禽`/`野兽` → 票数；随时间上涨 |

> 注：`jqys` 为后加字段，**上线前**的既有记录（`0292` 早期条目及更早各期）不含该键，读取时请容错。

## 怎么用

固定 `period`，把记录按 `t` 排序：

- 九肖 `n` 的曲线 = **进场节奏**（大家几点开始投）
- 九肖 `votes[肖]` 的曲线 = **各肖爬升**（谁在下午猛涨）
- 每小时取 `votes` 前 3 = **头部换位**（有没有暗马反超）
- 家禽野兽 `jqys.n` = **该玩法进场节奏**；`jqys.votes` 的 `家禽`−`野兽` 差 = **多空力量对比**（谁越拉越多）

示例（Python）：

```python
import json
recs = json.load(open("data/0291.json", encoding="utf-8"))
for r in recs:
    top3 = sorted(r["votes"].items(), key=lambda x: -x[1])[:3]
    j = r["jqys"]
    print(r["t"], "九肖n=%d" % r["n"], top3,
          "| 家禽野兽 n=%d" % j["n"], j["votes"],
          "差=%+d" % (j["votes"]["家禽"] - j["votes"]["野兽"]))
```

## 数据来源与说明

- 来源：第三方论坛公开接口（只读 GET）：
  - `.../h5/index/apiHost` → 动态域名
  - `.../h5/index/lastLotteryRecord?lotteryType=2` → 当期期号 / 开奖时刻
  - **九肖**：`{host}/forums/h5/prediction/rank?type=1&predictionTypeId=31&lotteryType=2…` → 连中榜名单
  - **九肖**：`{host}/forums/h5/prediction/prediction/detail?userId=…&predictionTypeId=31…` → 每人选肖明细
  - **家禽野兽**：`{host}/forums/h5/prediction/predictionList?lotteryType=2&title=家禽野兽…` → 当期发帖列表（按 `predictionId` 去重）
  - **家禽野兽**：`{host}/forums/h5/prediction/prediction/detail?userId=…&predictionTypeId=62…` → 每人当期选「家禽/野兽」
- **九肖票数 = 当前连中榜成员对该期的选肖累加**。榜单每期轮换，因此同一旧期的票数会随时间漂移 —— 这正是需要「当期定时快照」的原因。
- **家禽野兽票数 = 该玩法当期全部发帖人**的「家禽/野兽」计数（不进榜单，发帖即锁定）。
- 采集脚本 `collect.py` 只用 Python 标准库。

## 已知限制

- GitHub Actions 的 `cron` 会延迟数分钟，高负载时段**整档丢弃**（实测 8 小时只活 8 次，丢约一半）。已改为**每小时 4 档冗余**（:08/:23/:38/:53）打霰弹缓解，仍可能个别缺档（缺一条，不影响换期）。
- 第三方接口可能变更（域名轮换 / 字段调整），届时采集会失效并报错。
